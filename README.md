# 📚 BookFlow API

🇬🇧 [English](./README.md) | 🇷🇺 [Русский](./README.ru.md)

A RESTful API service for managing a personal library. Users can build a shared book catalog, add titles to their personal bookshelf with reading statuses, rate books, filter records, and retrieve top-rated books.

## 🛠 Tech Stack

* **Language:** Python 3.11+
* **Framework:** FastAPI
* **Validation & Settings:** Pydantic v2, pydantic-settings
* **Database & ORM:** PostgreSQL 16, SQLAlchemy 2.0 (asyncpg), Alembic
* **Caching:** Redis 7
* **Authentication:** JWT tokens (OAuth2 Password Flow), password hashing (bcrypt)
* **Testing:** Pytest, HTTPX (`AsyncClient`)
* **Containerization:** Docker, Docker Compose

## ✨ Key Features & Architecture

* **Users & Authentication:** User registration, OAuth2 password authentication with JWT token issuance, and current user profile retrieval.
* **Book Catalog (CRUD):** Create books, browse with pagination (`limit`/`offset`) and query filters, and fetch top-N books ranked by average rating. Updating and deleting records are restricted strictly to their creators (ownership verification).
* **Personal Bookshelf:** Add books to a personal shelf with a reading status (*plan to read*, *reading*, *completed*), update statuses and ratings, and filter shelf items by status.
* **Versioned Key Caching (Redis):** Top-rated book queries (`/api/v1/books/top`) are cached in Redis using versioned keys. Whenever a rating is added or updated on a shelf, the cache version is incremented and stale entries expire automatically via TTL—avoiding blocking key-pattern scans.
* **Repository Pattern:** Database and cache operations are isolated in a dedicated data-access layer (`repository.py`).
* **Custom Exception Handling:** Structured JSON error responses for authentication failures, insufficient permissions (`403 Forbidden`), and missing resources (`404 Not Found`).

## 🚀 Quick Start (Docker)

1. **Clone the repository:**
   ```bash
   git clone https://github.com/alex-p-89/bookflow.git
   cd bookflow
   ```

2. **Configure environment variables:**
   Create a `.env` file from the provided template and fill in your credentials (PostgreSQL, Redis, and JWT secret key):
   ```bash
   cp .env.example .env
   ```

3. **Run the application:**
   ```bash
   docker-compose up --build -d
   ```

On startup, PostgreSQL and Redis pass healthchecks, database migrations (`alembic upgrade head`, including initial catalog seeding) run automatically, and the Uvicorn server starts.

The API will be available at `http://localhost:8000`.

## 📖 API Documentation

Interactive API documentation is auto-generated by FastAPI and available once the service is running:
* **Swagger UI:** [http://localhost:8000/docs](http://localhost:8000/docs)
* **ReDoc:** [http://localhost:8000/redoc](http://localhost:8000/redoc)

### Core Endpoints

| Method | Endpoint | Description | Access |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/v1/auth/register` | Register a new user | Public |
| `POST` | `/api/v1/auth/login` | Authenticate and obtain a JWT token | Public |
| `GET` | `/api/v1/users/me` | Retrieve current user profile | Authenticated |
| `GET` | `/api/v1/books/` | List books with pagination and filters | Public |
| `POST` | `/api/v1/books/` | Add a new book to the catalog | Authenticated |
| `GET` | `/api/v1/books/top` | Top-N books by average rating (Redis-cached) | Public |
| `GET` | `/api/v1/books/{book_id}` | Get detailed book information | Public |
| `PUT` | `/api/v1/books/{book_id}` | Update book details | Owner only |
| `DELETE` | `/api/v1/books/{book_id}` | Delete a book from the catalog | Owner only |
| `GET` | `/api/v1/shelf/` | View personal bookshelf with status filter | Authenticated |
| `POST` | `/api/v1/shelf/` | Add a book to the personal bookshelf | Authenticated |
| `POST` | `/api/v1/shelf/{book_id}` | Update reading status and book rating | Shelf owner |

## 🧪 Running Tests

Tests are excluded from the production Docker image (via `.dockerignore`) and run locally against an isolated **in-memory SQLite** database (`aiosqlite`), so no running PostgreSQL or Redis instances are required.

1. **Install dependencies (if running locally for the first time):**
   ```bash
   pip install -r requirements.txt
   ```

2. **Execute the test suite from the project root:**
   ```bash
   pytest
   ```
